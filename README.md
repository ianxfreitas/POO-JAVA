☕ Programação Orientada a Objetos

Repositório dedicado aos estudos e práticas da disciplina de Programação Orientada a Objetos (POO), explorando os paradigmas fundamentais do desenvolvimento de software moderno através da linguagem Java.

🎯 Sobre o Repositório

Este espaço reúne projetos, exercícios e implementações que demonstram a aplicação dos princípios da orientação a objetos. Cada código reflete a evolução do pensamento em POO, desde conceitos básicos até padrões de projeto avançados.

🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java 
- **IDE:** Apache NetBeans

🎓 Objetivos de Aprendizado

Desenvolver a capacidade de modelar problemas reais utilizando o paradigma orientado a objetos, criando sistemas robustos, escaláveis e de fácil manutenção.
